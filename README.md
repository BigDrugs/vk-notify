# 📬 vk-notify

**Пуш-уведомления ВКонтакте на iPhone — через Telegram-бота.**

![Python](https://img.shields.io/badge/python-3.10+-blue)
![Platform](https://img.shields.io/badge/платформа-Linux%20%2B%20systemd-lightgrey)
![Deps](https://img.shields.io/badge/зависимости-requests%20%2B%20dotenv-green)

После удаления приложений VK из App Store (июнь 2026) Apple отозвала их push-токены —
уведомления на iOS перестали приходить насовсем. `vk-notify` решает это без PWA:
скрипт на вашем сервере слушает VK Long Poll и пересылает входящие сообщения
в Telegram-бота, чьи пуши работают штатно. А отвечать можно прямо из Telegram.

```
VK  ──Long Poll──▶  ваш сервер  ──бот──▶  Telegram  ──push──▶  iPhone
VK  ◀──messages.send──  ваш сервер  ◀──reply──  Telegram
```

## ✨ Возможности

| | |
|---|---|
| 💬 | Уведомления о личных сообщениях и беседах, с именем отправителя и текстом |
| 🖼 | Фото и стикеры приходят картинкой, голосовые — voice-сообщением, файлы — документом |
| ↩️ | **Ответы из Telegram**: reply на уведомление (текст или фото) → уходит собеседнику в VK, бот подтверждает реакцией 👍 |
| 🔕 | Заглушенные в VK чаты не беспокоят (режим настраивается) |
| 🚨 | Если VK-токен протух — бот сам предупредит и подскажет, как обновить |
| 🕵️ | Приватный режим: только «новое сообщение от X», без текста и медиа |

## 🚀 Установка

На сервере (Ubuntu/Debian, от root) — одна команда:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/BigDrugs/vk-notify/main/setup.sh)
```

Скрипт склонирует репозиторий в `/opt/vk-notify`, спросит три значения (ниже — где
их взять), настроит venv и systemd-сервис с автозапуском. Повторный запуск той же
команды обновляет код, не трогая настройки.

### Где взять токены

1. **VK-токен** — откройте [vkhost.github.io](https://vkhost.github.io) →
   **Kate Mobile** → «Разрешить» → из адресной строки скопируйте значение
   `access_token=…` (до `&`). Токен даёт полный доступ к аккаунту —
   **никому не показывайте**; действует до смены пароля.
2. **Токен бота** — в Telegram: [@BotFather](https://t.me/BotFather) → `/newbot`.
3. **Ваш chat_id** — спросите у [@userinfobot](https://t.me/userinfobot).
   После создания бота **напишите ему `/start`** — иначе он не сможет писать вам первым.

## ⚙️ Настройки

`/opt/vk-notify/.env`, после правок — `systemctl restart vk-notify`:

| Переменная | Что делает |
|---|---|
| `ONLY_PRIVATE=true` | только личные сообщения, без бесед |
| `FORWARD_TEXT=false` | приватный режим: только «новое сообщение», без текста и медиа |
| `MUTED_MODE` | заглушенные в VK чаты: `skip` — не пересылать (по умолчанию), `silent` — слать без звука |
| `IGNORE_PEER_IDS` | чёрный список peer_id через запятую (беседы: `2000000000+номер`) |

## 🔧 Обслуживание

```bash
journalctl -u vk-notify -f        # логи
systemctl restart vk-notify       # перезапуск
```

Обновление кода: повторно выполнить команду установки, либо для разработки —
`deploy.sh` (заливка одного файла) / `install.sh` (полная установка) с локальной
машины; хост задаётся `DEPLOY_HOST=root@1.2.3.4` или файлом `.deploy-host`.

На iPhone: закрепите чат с ботом и поставьте ему отдельный звук — уведомления VK
будет не спутать с остальным Telegram.

## 🗑 Удаление

```bash
systemctl disable --now vk-notify
rm -rf /opt/vk-notify /etc/systemd/system/vk-notify.service
systemctl daemon-reload
```

Затем отзовите доступы: VK-токен — смените пароль VK или «Настройки → Безопасность →
Завершить все сеансы»; бота — [@BotFather](https://t.me/BotFather) → `/deletebot`.

## 📝 Заметки

- Ответы (reply) привязываются к уведомлениям в памяти процесса: после перезапуска
  сервиса отвечать можно только на новые уведомления.
- Скрипт не помечает сообщения прочитанными и не влияет на статус «онлайн».
- Видео и музыка приходят текстовой пометкой — VK не отдаёт на них прямые ссылки.
- Лимит Telegram на файлы по ссылке — 20 МБ; что не пролезло, придёт пометкой.

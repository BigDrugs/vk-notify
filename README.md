# vk-notify

Мост VK ↔ Telegram: слушает VK User Long Poll и присылает уведомления о входящих
сообщениях в Telegram-бота. Решает проблему отозванных Apple push-токенов VK на iOS.

Возможности:
- уведомления о личных сообщениях и беседах, с типами вложений (фото, голосовое, стикер…);
- фото и стикеры приходят картинкой, голосовые — voice-сообщением прямо в TG
  (при `FORWARD_TEXT=false` содержимое не пересылается);
- **ответы из Telegram**: reply на уведомление → текст или фото уходит собеседнику в VK
  (бот подтверждает отправку реакцией 👍);
- учитывает заглушенные в VK чаты (`MUTED_MODE`);
- алерт в Telegram, если VK-токен перестал работать (и «токен снова работает» после починки).

## 1. Получить VK-токен

1. Откройте https://vkhost.github.io с компьютера.
2. Выберите **Kate Mobile** (у неё есть доступ к сообщениям), нажмите «Разрешить».
3. Из адресной строки после редиректа скопируйте значение `access_token=...` (до `&`).
   Это токен вашего аккаунта — **никому не показывать**, действует до смены пароля.

## 2. Создать Telegram-бота

1. В Telegram напишите @BotFather → `/newbot` → получите `TG_BOT_TOKEN`.
2. Напишите своему боту любое сообщение (иначе он не сможет писать первым).
3. Узнайте свой `TG_CHAT_ID`: напишите @userinfobot, либо откройте
   `https://api.telegram.org/bot<TOKEN>/getUpdates` и возьмите `message.chat.id`.

## 3. Установка на VPS

**Одной командой прямо на сервере** (спросит токены, поставит всё в `/opt/vk-notify`
и запустит с автостартом):

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/BigDrugs/vk-notify/main/setup.sh)
```

Либо с локальной машины, если репозиторий уже склонирован и `.env` заполнен:

```bash
cp .env.example .env   # вписать токены
./install.sh           # или DEPLOY_HOST=root@1.2.3.4 ./install.sh
```

Вручную то же самое: скопировать `vk_notify.py`, `requirements.txt`, `.env` в
`/opt/vk-notify`, создать venv и поставить зависимости, положить
`vk-notify.service` в `/etc/systemd/system/` и включить сервис. Другой
пользователь/пути — поправьте `User=` и пути в `vk-notify.service`.

## Обновление кода

```bash
./deploy.sh          # залить vk_notify.py, перезапустить, показать статус и логи
./deploy.sh --full   # + requirements.txt и systemd-юнит (когда менялись)
```

Хост задаётся переменной `DEPLOY_HOST=root@1.2.3.4` или один раз в файле
`.deploy-host` рядом со скриптом (в git не попадает).

## Настройки (.env)

| Переменная | Что делает |
|---|---|
| `ONLY_PRIVATE=true` | только личные сообщения, без бесед |
| `FORWARD_TEXT=false` | не пересылать текст, только «новое сообщение от X» (приватнее) |
| `IGNORE_PEER_IDS` | не уведомлять об этих peer_id (беседы: `2000000000+номер`) |
| `MUTED_MODE` | заглушенные в VK чаты: `skip` — не пересылать (по умолчанию), `silent` — слать в TG без звука |

## На iPhone

Уведомления приходят как обычные сообщения от вашего бота в Telegram — пуши
работают штатно. Чтобы отличать их от остального Telegram: чат с ботом →
закрепить и/или выставить отдельный звук уведомления.

## Заметки

- Токен Kate Mobile перестаёт работать после смены пароля VK или «завершить все
  сеансы» — бот пришлёт алерт, получить заново (шаг 1) и обновить `.env`.
- Привязка «уведомление → собеседник» для ответов хранится в памяти процесса:
  после перезапуска сервиса reply работает только на новые уведомления.
- Скрипт только читает Long Poll и ничего не отправляет в VK — на «онлайн»
  статус не влияет (mode без флага онлайна), сообщения не помечает прочитанными.
